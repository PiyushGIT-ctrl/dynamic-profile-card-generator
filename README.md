# dynamic-profile-card-generator
A simple web app that takes user input and generates profile cards dynamically using JavaScript.

## Features
- Dynamic DOM manipulation
- Real-time card creation
- Image rendering via URL
- Clean UI with reusable CSS classes

## Tech Used
- HTML
- CSS
- JavaScript (Vanilla)

## What I learned
- createElement, appendChild
- Event listeners (submit)
- Handling user input
- DOM structuring
